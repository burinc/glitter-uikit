# Demos

Screenshots of glitter-uikit's interactive demos, rendered through AppKit. Regenerate with `screen-grab shot --manifest scripts/demo_manifest.edn` (needs macOS Screen Recording permission). The images here are committed, so you do not need the capture tool to browse them.

## basics

### counter

The canonical demo. One state atom, a pure state -> hiccup view, handlers as data.

![counter](counter.png)

### todo

A task board on glitter.nexus: derived counts computed inline, an entry, and checkbutton toggles.
